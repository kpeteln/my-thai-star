## 7. NgRx State Flow — Order & Booking

Shows the Redux-pattern data flow for order management in the Angular frontend.

```mermaid
sequenceDiagram
    participant U as 👤 User
    participant C as Angular Component<br/>(MenuComponent)
    participant A as NgRx Action
    participant E as NgRx Effect
    participant API as Backend REST API<br/>(/mythaistar/services/rest)
    participant R as NgRx Reducer
    participant S as NgRx Selector
    participant V as View Template

    Note over U,V: Browsing Menu and Adding Dish to Order Basket

    U->>C: Clicks "Add to Order"
    C->>A: dispatch(addToBasket({ dish }))
    A->>R: orderReducer handles ADD_TO_BASKET
    R->>S: State updated: basket[]
    S->>V: basketCount$ | async → header badge
    V-->>U: Cart icon shows updated count

    Note over U,V: Submitting Booking + Order

    U->>C: Fills booking form, submits
    C->>A: dispatch(saveBooking({ bookingData }))
    A->>E: BookingEffects.saveBooking$
    E->>API: POST /bookingmanagement/v1/booking
    API-->>E: 201 Created { bookingToken }
    E->>A: dispatch(saveBookingSuccess({ token }))
    A->>R: bookingReducer sets currentBookingToken
    E->>A: dispatch(saveOrder({ token, orderLines }))
    A->>E: OrderEffects.saveOrder$
    E->>API: POST /ordermanagement/v1/order
    API-->>E: 201 Created
    E->>A: dispatch(saveOrderSuccess())
    A->>R: orderReducer clears basket
    R->>S: basket$ emits []
    S->>V: Basket cleared, confirmation shown
    V-->>U: ✅ Success notification (SnackBar)

    Note over U,V: Error Handling

    E->>API: POST fails (network / 4xx / 5xx)
    API-->>E: Error response
    E->>A: dispatch(saveBookingFailure({ error }))
    A->>R: errorReducer stores error message
    R->>S: error$ emits message
    S->>V: Error message shown
    V-->>U: ❌ Error SnackBar notification
```
